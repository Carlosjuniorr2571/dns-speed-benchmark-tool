Test response time for 40+ public DNS servers from your location and apply the fastest one in one click. Includes Cloudflare, Google, Quad9, NextDNS, and AdGuard.

## Features

- Tests 40+ public DNS servers simultaneously
- Shows average, minimum, and maximum response times
- Ranks results by speed from your specific network location
- One-click apply: sets the winner as your system DNS immediately
- Scheduled weekly auto-benchmark to keep settings optimal

## FAQ

**Is Cloudflare always the fastest?**  
Not necessarily. Results vary by location and ISP - that's the whole point of benchmarking.

**Will changing DNS break anything?**  
No. DNS only affects name resolution. Revert to automatic at any time in network settings.
